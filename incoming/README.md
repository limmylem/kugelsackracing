# incoming

Drop new models here, named `<type>_<name>.glb` (`spoiler_ducktail.glb`, `rim_5spoke.glb`,
`car_roadster.glb`), and run `npm run import`. Each is checked, fixed, checked again and put in the
game; the original moves to `incoming/imported/`. A model that still has problems stays here, with what
to fix printed. See docs/MODELLING_GUIDE.md.
